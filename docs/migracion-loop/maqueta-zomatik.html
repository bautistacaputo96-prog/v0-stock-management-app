Cómo funciona

• Sin nota de pedido en Zomatik no se despacha: lo controla la base, para todas las pantallas.
• El plantista no genera NP: se genera al programar. Si quedó pendiente (Zomatik caído), se resuelve en Programación; desde acá se avisa.
• Si Zomatik no responde, un gerencial (Bautista, Juan o Fernando) puede autorizar este pedido por hoy, con motivo. El sistema reintenta la NP cada 10 min y no deja remitir hasta tenerla.
• Un error de datos (cliente sin código, proyecto sin saldo) no se saltea: hay que arreglarlo.
